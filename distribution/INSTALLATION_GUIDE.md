# 安装与首次配置

本安装包只包含程序和通用示例配置，不包含任何人的微信账号、联系人、聊天记录、口令或 Codex 登录信息。

## 安装前

- Windows 10/11 64 位。
- 安装并登录 Windows 微信。
- 如需 AI 回复，另行安装 Codex CLI，并在本机完成登录；模型权限由使用者自己的 Codex 账号决定。仅登录 Codex 桌面版不代表命令行已可用。
- 本程序通过桌面界面定位和操作微信，不是微信官方功能；窗口遮挡、系统缩放或微信更新都可能影响识别，存在误发或账号风控风险。

## 首次配置

1. 安装结束时选择“启动程序并完成首次配置”。首次启动窗口会让你选择微信数据库根目录，并填写当前账号的文件夹名称。窗口只检查所选文件夹和账号子目录是否存在，不打开或扫描聊天文件。
2. 保存前会在安装目录中备份原有 `config.json`。首次配置保持全局自动回复关闭、试运行开启、远程指令关闭，不自动读取或添加联系人。
3. 配置文件位于安装目录的 `_internal\config.json`。也可以从开始菜单选择“编辑本机配置”。
4. 用户取消首次配置时，程序不会进入主界面；之后可从开始菜单再次启动并完成配置。
5. 如果启用 Codex 指令，务必只允许可信联系人，并自行设置指令密码和工作目录；安装包默认关闭该功能。
6. “交给 Codex 的配置说明”位于开始菜单和安装目录的 `docs` 文件夹，可供新电脑上的 Codex 按安全边界协助配置。

程序需要本机微信客户端和本机 Codex 登录环境；安装包不提供、复制或共享账号认证凭据。卸载程序不会替你删除微信数据。

## 当前发行候选限制

- 这是未签名的测试发行候选；Windows 可能显示未知发布者提示。
- 还没有设置本软件自身的分发许可证，也没有进行独立电脑上的安装和微信运行验证；公开发布前需确认版权/许可证、第三方许可、隐私说明和实际运行兼容性。
- 本安装程序不会自动启动微信或发送消息。
