# 安装与首次配置

本安装包只包含程序和通用示例配置，不包含任何人的微信账号、联系人、聊天记录、口令或 Codex 登录信息。

## 安装前

- Windows 10/11 64 位。
- 安装并登录 Windows 微信。
- 如需 AI 回复，另行安装 Codex CLI，并在本机完成登录；模型权限由使用者自己的 Codex 账号决定。仅登录 Codex 桌面版不代表命令行已可用。
- 本程序通过桌面界面定位和操作微信，不是微信官方功能；窗口遮挡、系统缩放或微信更新都可能影响识别，存在误发或账号风控风险。

## 首次配置

1. 安装结束时选择“启动程序并完成首次配置”。先登录 Windows 微信 4.x，再在向导中选择本机微信文件夹。可以选 `xwechat_files`、当前账号文件夹或 `db_storage`，向导会识别目录层级并列出账号，无需手写账号标识。
2. 选择当前登录账号。向导会检查 `db_storage` 下是否存在 `session.db`（允许位于子目录），此时只检查文件名和位置，不读取数据库内容。
3. 点击“保存并读取近期联系人”，在当前账号的最近 100 条会话中筛选最多 30 个个人联系人；群聊、公众号不列入，只有收到消息的个人会话也可显示。也可以点击“保存配置，稍后读取”。读取名单后所有联系人默认不监听、不自动回复，全局自动回复关闭、试运行开启、远程指令关闭。
4. 如需调整数据目录或重新读取联系人，先关闭主程序，再从开始菜单打开“重新配置微信与联系人”。切换账号会清空本程序旧联系人和指令授权；重新配置后需要重新选择监听和自动回复权限。
5. 配置文件位于安装目录的 `_internal\config.json`，保存前原文件会备份到 `_internal\backups\first-run\`。也可以从开始菜单选择“编辑本机配置”。
6. 用户取消首次配置时，程序不会进入主界面；之后可从开始菜单再次启动并完成配置。
7. 如果启用 Codex 指令，请只允许可信联系人，并自行设置指令密码和工作目录。AI 回复需要本机 Codex CLI 已安装并登录；配置向导不提供账号认证。
8. “交给 Codex 的配置说明”位于开始菜单和安装目录的 `docs` 文件夹，默认参数说明见 `CONFIG_TUNING.md`。

程序需要本机微信客户端和本机 Codex 登录环境；安装包不提供、复制或共享账号认证凭据。卸载程序不会替你删除微信数据。

## Codex 路径无法访问时

1.0.8 会在使用 AI 回复或风格生成时寻找 Codex CLI，跳过 Windows 无法访问的路径，不会因为固定路径的 WinError 448 关闭主界面。普通路径查找优先使用 PATH 中的原生程序，也支持常见 npm 安装目录。

如果仍提示没有可用的 CLI，请确认 Codex CLI 已安装并登录。在主界面模型设置区域点击“选择 Codex 程序…”，选择本机可访问的实际 `codex.exe` 文件；程序会备份配置并保存位置，之后的 AI 回复、风格生成和远程 Codex 指令使用该设置。点击“恢复自动查找”可清除指定位置。不需要手写 JSON，也不要选择 `.cmd` 或快捷方式。

自动查找覆盖 PATH、常见 npm 的新旧原生程序目录、用户目录下 `.local\bin` 与 `.cargo\bin`、CARGO_HOME 和 WinGet 链接位置；访问失败时继续查找。不自动安装 CLI、复制认证或启动登录。指定位置仍不能启动时，程序尝试其他已安装位置并显示明确提示。

升级安装会保留已有 `_internal\config.json`；已有配置没有 `codex_executable` 字段时自动使用路径查找，不必重设联系人。

## CLI 版本与模型列表（1.0.9）

主界面打开后，会在后台读取本机 CLI 版本、exec 功能和 CLI 返回的模型目录。点击“刷新模型列表”可重新查询；切换 CLI 程序位置后也会刷新。查询不生成模型回复、不发送微信消息，也不替用户安装、升级或登录。

模型下拉框采用 CLI 返回的文字模型目录，推理档位采用该模型返回的支持值。选好后点击“应用模型”，模型及当前选择的档位会一起保存；保存前备份原配置。刷新不会自动改动当前模型、档位、联系人或发送权限。

CLI 的模型目录可能来自缓存，并非逐项验证了账号调用权限。实际可用性以模型调用结果为准；切换登录账号后请重新刷新。程序不会读取、显示或复制登录令牌，登录状态只显示“已登录”“未登录”或“未知”。

旧 CLI 没有目录查询能力、登录未完成或查询失败时，只显示原设置并标记“未核实”，不会重新显示固定预设模型作为可用列表。缺少本程序调用所需的参数时会列出缺项并提示升级，AI 任务在执行前停止；不通过删除试运行、隔离或隐私相关参数兼容旧版。
