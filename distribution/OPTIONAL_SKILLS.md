# 可选技能：微信聊天记录读取

`optional-skills/get-wechat-history/SKILL.md` 随通用包提供，作为 AI 的操作规范副本。它可帮助使用者理解如何通过对应 MCP 插件读取、搜索或导出本机微信记录。

这个文件本身不是可运行插件：包内不含 MCP 服务端、Codex 插件注册、账户密钥、数据库或聊天内容。新电脑必须由使用者单独安装/连接相应插件，并在自己的 Codex 环境中初始化；首次初始化需要微信桌面端登录及当前账号对应的数据路径。

读取聊天记录不是自动回复配置的必要步骤。AI 只能在使用者明确提出读取/分析请求后，使用该插件提供的工具，遵守所请求的联系人、群和时间范围。若插件不可用，不能改用终端扫描或其他方式读取数据库。导出的聊天记录可能带有完整原始内容，必须妥善保密。
