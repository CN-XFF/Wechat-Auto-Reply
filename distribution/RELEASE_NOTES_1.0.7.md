# 微信自动回复助手 1.0.7

- 安装后通过向导选择本机微信数据目录和账号，无需手写 JSON、数据库路径或账号标识。
- 支持选择 xwechat_files、账号或 db_storage 文件夹，并校验子目录中的 session.db。
- 点击“保存并读取近期联系人”后列出本机近期个人会话；监听和自动回复默认关闭。
- 开始菜单增加“重新配置微信与联系人”；切换账号时清空本程序旧联系人和指令授权，保存前备份配置。
- 通用模板采用日常聊天平衡参数：medium 推理、2400 字上下文和合并消息上限、2 秒轮询、100 条近期会话扫描。

安装包不包含个人配置、微信数据库、聊天记录或登录凭据。Windows 微信 4.x 需在本机登录，AI 回复另需已登录的 Codex CLI。

此安装包未签名。构建与自动化专项检查不代表已在另一台电脑验证微信数据库兼容性、联系人定位或真实发送。
