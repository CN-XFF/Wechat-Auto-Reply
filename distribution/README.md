# 微信自动回复助手：安装后使用说明

安装完成后启动程序，先登录本机 Windows 微信 4.x，再通过首次配置向导选择微信数据位置和当前账号。

点击“保存并读取近期联系人”可以导入近期个人联系人名单。首次默认关闭监听、自动回复和远程指令，并开启试运行；导入名单不会开启发送。

需要修改微信目录、切换账号或重新读取名单时，先关闭主程序，再从开始菜单选择“重新配置微信与联系人”。AI 回复还需要本机安装并登录 Codex CLI。

若提示找不到 Codex 程序，在主界面的模型设置区域点击“选择 Codex 程序…”选择本机实际 codex.exe；之后的 AI 功能使用该设置。也可以点击“恢复自动查找”。程序启动不会再因固定 Codex 路径不可访问而退出。

1.0.9 会在后台检查 CLI 版本并刷新模型目录，也可点击“刷新模型列表”。选定模型后点击“应用模型”；模型和推理档位保存前会备份。目录可能来自 CLI 缓存，账号权限以实际调用为准。旧版缺少必要功能时提示升级，刷新失败时保留原设置。

本目录包含：

- `INSTALLATION_GUIDE.md`：安装、首次配置、重新配置和限制说明。
- `CONFIG_TUNING.md`：通用参数及首次使用说明。
- `CODEX_AFTER_INSTALL_HANDOFF.md`：交给 Codex 的本机配置说明。
- `CHANGELOG.md`：程序版本更新记录。
- `RELEASE_NOTES_1.0.9.md`：本次安装包改进摘要。

配置文件在安装目录的 `_internal\config.json`，向导保存前会备份到 `_internal\backups\first-run\`。安装包不包含个人配置、聊天记录或登录凭据。

桌面自动化会受微信版本、窗口大小和系统显示设置影响；本工具不是微信官方自动回复功能。此安装包未签名，尚未在独立电脑上验证安装及微信运行。
