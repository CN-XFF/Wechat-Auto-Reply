# WeChat Auto Reply 1.0.6

This pre-release contains the application source updates recorded in `CHANGELOG.md`, refreshed Windows packaging, and a sanitized generic example configuration.

## Requirements

- Windows 10/11 x64 and a locally installed Windows WeChat client.
- Codex CLI is needed only for AI-generated replies and must be installed and authenticated by the user.

## Before enabling real sending

The installer is unsigned. Review the local configuration after installation. The first-run defaults keep global auto-reply disabled and trial mode enabled. This build was packaged on the development machine; installation and live WeChat behavior have not been independently verified on a separate computer.
