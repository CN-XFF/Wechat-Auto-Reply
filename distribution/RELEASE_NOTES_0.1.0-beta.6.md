# 微信自动回复助手 0.1.0-beta.6

Windows x64 测试版安装程序。请先阅读安装说明和隐私、安全提示。

## 本版内容

- 安装后提供首次配置窗口，用于选择本机微信数据目录并设置账号目录名。
- 初始状态保持自动回复关闭、试运行开启、远程指令关闭，不自动读取近期联系人。
- 安装目录包含安装指南和可交给 Codex 的迁移配置说明。

## 运行要求与限制

- Windows 10/11 64 位、Windows 桌面微信。
- 使用 AI 回复时，需要另外安装并登录本机 Codex CLI。
- 该安装程序未进行独立电脑安装验证或真实微信运行验证；它是测试候选，不代表消息发送已验证。
- 安装程序未签名，Windows 可能显示未知发布者提示。

发布前请确认本项目许可证、第三方分发条件、隐私说明，并在独立 Windows 电脑上检查安装和首次配置流程。
